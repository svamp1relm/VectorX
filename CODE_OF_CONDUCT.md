# Code of Conduct

Участники VectorX должны взаимодействовать уважительно, конструктивно и без дискриминации.

Ожидаемое поведение:

- обсуждать технические решения по существу и с воспроизводимыми данными;
- уважать разный опыт исследователей и разработчиков;
- ясно разделять факты, гипотезы и ограничения verification;
- принимать обратную связь и не преследовать участников.

Недопустимы harassment, персональные атаки, публикация чужих private данных и умышленное нарушение
безопасности пользователей.

О нарушениях можно сообщить владельцу репозитория через GitHub. Maintainer рассматривает жалобы
приватно и может ограничить участие нарушителя в проекте.

Принципы основаны на Contributor Covenant 2.1.
